# Woowfy Brand Kit v2

Este paquete reemplaza el anterior. Los logos se generan desde un único master vectorial para evitar deformaciones, fondos incrustados o composiciones inconsistentes.

## Formatos
- SVG: logos editables y escalables.
- PNG: exportaciones listas para web/diseño.
- ICO/PNG: favicon y Apple Touch Icon.
- OG/social: imágenes 1200x630, 1080x1080, 1080x1920 y 1920x1080.
- Brand board: identidad visual.
- CSS/JSON: colores oficiales.
